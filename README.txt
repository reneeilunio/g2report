EUROPA — Art of Emerging Europe

Static website for GitHub Pages. Files: index.html, style.css, script.js.

To publish: upload the three files to the repository root (or extract this ZIP into the repository), commit changes, then enable GitHub Pages from Settings > Pages if not already enabled.

The site requires no database, login, or backend. Passport progress is stored in the visitor’s browser using localStorage. Ask the Artist is a curated simulated guide, not a live AI.

Content follows the provided class presentation. Date ranges and examples are retained as shown in the slides, including places where the presentation’s date ranges overlap or artwork classifications may need confirmation from the instructor.
